# Daniel Rios · Portfólio

Portfólio pessoal de Daniel Rios, AI Builder em GTM, RevOps, Product, Sales e Dados.

## Rodar localmente

```bash
python3 -m http.server 8000
# abra http://localhost:8000
```

Sem dependências e sem build: HTML, CSS e JavaScript puros.

## Publicação

O destino planejado é GitHub Pages no repositório público `danielcunharios/portfolio-dr`,
em `https://danielcunharios.github.io/portfolio-dr/`. O diretório local já está
conectado ao remoto `origin`; ainda não há commit ou publicação.

Os dados não confirmados foram omitidos; as imagens no portfólio são de
propriedade do autor. Configure GitHub Pages para publicar a branch `main` a
partir da raiz do repositório.

## Editar conteúdo

O conteúdo fica em `assets/js/data.js` (contatos, cases, projetos e stack). A estrutura e os textos fixos ficam em `index.html`. As instruções completas para levar o site a produção estão em `CLAUDE.md`.
